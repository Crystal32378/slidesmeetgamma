## 注意事項

1. **用字一致**：「想認識」「連結成立」「邀請已送出」三個詞要一直用同一組，不要混成「配對成功」「已配對」。
2. **不寫推測**：推薦理由與破冰句要以資料為依據，不寫「一定」「完美」這類字眼（server 的 prompt 也禁止）。
3. **Demo 誠實**：「我先試玩」一定要讓人知道是虛構角色，不能讓人以為是真人。
4. **英文與中文活動名**：英文名 `Gamma Community Exclusive`；中文名 `Gamma 社群專屬` 是暫定，待你確認。

> 更新（第五輪）：上述建議已套用，並依最新指示修正：活動名「Gamma Community Exclusive」、中文「Gamma 社群限定」、產品名保留 Slides Meets Gamma、「不必用 email 註冊」、Gamma key 說明改為經伺服器轉送且暫存記憶體、不承諾刪除時間、破冰句沒有實際共同點時不用「也」。
